# Mulai Langkahmu — ETOS ID Palu

Interactive event experience for Pembukaan Pembinaan ETOS ID Palu Semester 2 2026.

## Routes
- `/stage` — layar besar / main stage
- `/join?room=PALU26` — participant view
- `/control` — moderator control room

## Stack
- React + Vite
- Supabase Realtime / RPC
- Vercel

The ETOS Palu backend is isolated with the `etos_palu_*` namespace and does not modify Teman Digital application tables.
